# AI manager

Codex/MCP workflow for TradingView Desktop. See the [root setup guide](../README.md#use-the-ai-manager).

`scripts/` contains Windows launch and verification helpers. `skills/` contains workflow notes.
`vendor/tradingview-mcp/` contains the MIT-licensed upstream bridge plus local Windows launcher/health discovery modifications and the local lockfile.
Historical machine-specific notes, notebooks and research transcripts are not included.
